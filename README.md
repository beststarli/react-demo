# React Demo

## 简介
React Demo用来存放和展示一些React手撕题源码与效果，题目来源于个人与网络面经。
## 目前已有题目
- 实现倒计时：[countDown.tsx](./src/demo/countDown.tsx)

## 如何启动？
```bash
git clone '本项目地址'
cd react-demo

# 项目根目录下
npm install
npm run dev
```

## 目录结构
```
├─ public
├─ src
│  ├─ demo: 一些手撕题源码
│  ├─ index.css
│  ├─ app.tsx：顶层挂载根组件
│  ├─ index.tsx
│  └─ vite-env.d.ts
├─ .gitignore
```
